# Spork routing

Send an ordinary message to reach the chief. Prefix a message with `@researcher` for analysis, `@builder` for implementation advice, or `@crew` to gather both specialists and receive the chief's synthesis. The prefix must be the first text in the message.

Spork answers questions through the configured model endpoint. It currently has no tools or access to BB's workspace. Ask a BB provider with workspace tools when the task requires file edits or commands.
